# 네이버 제휴 발행 자동화 운영 문서

## 목적

이 프로젝트는 토스쇼핑과 향후 쿠팡 파트너스의 상품 정보를 검증 가능한 초안으로 만들고, 모바일 텔레그램 승인 후 네이버 블로그에 전체공개로 발행하는 승인 기반 자동화 시스템이다. 모든 공개 발행은 **모바일 승인**, **원본 이미지 확인**, **중복 방지**, **최종 URL 기록**을 전제로 한다.

> 비밀값, 로그인 정보, 브라우저 프로필, API 토큰, 데이터베이스 연결 정보는 소스 저장소·로그·진단 결과에 기록하지 않는다.

## 토스 운영 흐름

| 단계 | 자동화 책임 | 안전 조건 |
|---|---|---|
| 상품 수집 | 토스 상품·가격·제휴 링크·원본 이미지 후보 확인 | 품절, 이미지 없음, 링크 없음, 기존 발행 상품 제외 |
| 시간대별 초안 | 07:00에 4건, 12:00에 2건, 18:00에 4건 준비 | 일일 최대 10건, 상품 ID 중복 방지 |
| 모바일 승인 | 텔레그램 승인 메시지 전송 | 승인 또는 보류를 원자적으로 기록 |
| 순차 해제 | 승인된 큐에서 20분마다 1건씩 단건 배치 생성 | 같은 날 `RELEASED` 항목이 있으면 다음 항목을 해제하지 않음 |
| 네이버 입력 | 확장 프로그램이 제목·본문·일반 링크·원본 이미지 입력 | 링크 카드 금지, 이미지 확인 실패 시 공개 중단 |
| 전체공개 발행 | 카테고리·전체공개·최종 발행 버튼 재검증 | 승인 전 발행 금지, 공개 URL 미확인 시 자동 재클릭 금지 |
| 결과 기록 | 공개 URL·성공·실패 원인 기록 및 텔레그램 알림 | `PUBLISH_UNKNOWN`은 수동 확인 후에만 정리 |

## 정규 시간표

| 작업 | 시간 | 수량 | 비고 |
|---|---:|---:|---|
| 오전 토스 초안 준비 | 매일 07:00 | 4건 | 텔레그램 승인 요청 생성 |
| 정오 토스 초안 준비 | 매일 12:00 | 2건 | 텔레그램 승인 요청 생성 |
| 저녁 토스 초안 준비 | 매일 18:00 | 4건 | 텔레그램 승인 요청 생성 |
| 승인 후 순차 발행 | 매 20분 | 1건 | 승인된 대기열이 있을 때만 실행 |

초안 준비는 고정 시각에만 실행한다. 20분 해제 작업은 승인된 항목이 없으면 공개 탭을 열거나 글을 발행하지 않는다.

## 확장 프로그램 운영

확장 프로그램은 `네이버 초안 입력 도우미`이며, Manifest V3 기반으로 동작한다. 서비스 워커가 시작되면 승인 폴링을 재개하도록 구성되어 있다. 원본 이미지는 먼저 자동 준비를 시도하고, Chrome 보안 정책으로 자동 준비가 거부될 때에만 전용 탭의 수동 복구 버튼을 표시한다.

자동화가 만든 네이버 글쓰기 탭·이미지 준비 탭만 종료하며, 사용자가 열어 둔 Chrome 탭이나 창은 건드리지 않는다.

## 모바일 운영 원칙

텔레그램은 모바일 승인과 운영 알림의 단일 채널이다. 승인 채널에 전송되는 모바일 운영 패널에서 다음 기능을 사용할 수 있다.

| 기능 | 목적 | 공개 발행 안전성 |
|---|---|---|
| 오늘 현황 | 완료·대기·진행·실패·다음 일정 조회 | 조회 전용 |
| 오늘 일정 | 시간대별 준비·다음 해제 시각 확인 | 조회 전용 |
| 자동 발행 보류 | 승인된 큐의 후속 해제 중지 | 기존 공개 글에 영향 없음 |
| 자동 발행 재개 | 보류된 큐의 순차 해제 허용 | 기존 텔레그램 승인 항목만 대상 |
| 즉시 발행 요청 | 다음 승인 항목을 앞당겨 해제 | 현재는 제공하지 않음; 향후 별도의 이중 확인으로만 추가 |

`자동 발행 보류`는 이미 공개 완료된 글이나 승인 메시지를 되돌리지 않는다. 다음 20분 해제 작업만 멈춘다. `자동 발행 재개`는 기존 텔레그램 승인 항목만 다음 해제 시각부터 순차 처리하도록 허용한다.

## 쿠팡 확장 설계

쿠팡은 토스와 같은 승인·큐·네이버 발행 공통 파이프라인을 사용하되, 아래 상품 수집·본문 생성·고지 부분만 플랫폼별 모듈로 분리한다.

| 공통 계층 | 토스 모듈 | 쿠팡 모듈 |
|---|---|---|
| 상품 식별·중복 방지 | 토스 상품 ID | 쿠팡 상품 ID |
| 제휴 링크 | 토스 쉐어링크 | 쿠팡 파트너스 단축 링크 |
| 가격 검증 | 확인 가격 | 정상가·일반 할인가·조건부 최저가 |
| 이미지 검증 | 원본 대표 이미지 | 원본 대표 이미지 |
| 본문 템플릿 | 토스 수수료 고지 | 쿠팡 조건부 가격·파트너스 고지 |
| 승인·큐·발행 | 공통 | 공통 |

쿠팡 모듈 구현 전에는 쿠팡 파트너스 링크 발급 방식, 가격 조건의 검증 가능성, 원본 이미지의 직접 사용 가능 여부를 먼저 검토한다.

## 복구 원칙

1. 공개 클릭 전 실패는 `FAILED_PRE_SUBMIT`으로 남기고, 새 모바일 승인으로만 재시도한다.
2. 공개 클릭 후 URL을 확인하지 못하면 `PUBLISH_UNKNOWN`으로 기록하고 자동 재클릭하지 않는다.
3. 날짜가 바뀐 미발행 큐는 공개하지 않고 `SKIPPED`로 종료한 뒤 종료 이력으로 보존한다.
4. 시간대별 초안·큐 생성은 한국 표준시를 기준으로 한다.
5. 데이터베이스 또는 확장 프로그램 변경 뒤에는 무작정 발행하지 않고 승인 배치·대기열·URL 기록 상태를 진단한다.
