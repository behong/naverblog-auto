# 쿠팡 골드박스 후보 수집기

이 확장 프로그램은 **토스용 네이버 초안 입력 도우미와 별개**로 설치한다. 쿠팡 파트너스 골드박스 화면에서 공개 상품 카드의 상품 ID, 상품명, 표시 가격, 상품 URL, 대표 이미지 URL만 JSON으로 저장한다.

> 로그인 정보, 비밀번호, 쿠키, 세션 값, API 키는 읽거나 저장하지 않는다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 연다.
2. 우측 상단의 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택한다.
4. 이 디렉터리 `extension/coupang-goldbox-collector`를 선택한다.
5. 기존 **네이버 초안 입력 도우미**는 그대로 유지한다. 삭제·새로고침할 필요가 없다.

## 사용

1. 쿠팡 파트너스에 로그인한 뒤 골드박스 목록을 연다.
2. 목록이 충분히 표시된 뒤 Chrome 툴바의 **쿠팡 골드박스 후보 수집기**를 누른다.
3. **현재 골드박스 후보 저장**을 누른다.
4. 다운로드된 JSON은 후보 정보일 뿐이며, 제휴 링크, 정상가·일반 할인가·조건부 최저가, 원본 이미지 검증이 끝나기 전에는 발행에 사용할 수 없다.

## 다음 단계

수집된 후보의 실제 가격 조건과 파트너스 단축 링크를 검증하는 쿠팡 전용 승인 스크립트에 연결한다. 이 단계도 토스 대기열·예약·발행 코드와 분리한다.
