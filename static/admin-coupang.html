쿠팡 수집·발행 확장 연결

수집기는 골드박스 후보·링크·가격·원본 이미지를 확인합니다. 발행 도우미는 검증 통과 상품만 네이버 카테고리 42에 자동 공개합니다. 토큰은 화면에 표시되지 않고 각 확장 내부에만 보관됩니다.

두 확장을 각각 한 번 연결하면 됩니다.

WORKFLOW

쿠팡 발행 순서

아래 순서에서 가격·원본 이미지·제휴 링크 검증을 통과하지 못한 상품은 공개 발행으로 넘어가지 않습니다.

  1. 쿠팡 파트너스 골드박스에서 수집기로 현재 후보를 저장합니다.
  2. 정제 후보의 파트너스 링크를 생성하고, 상품 상세 화면에서 가격·조건·원본 이미지를 검증합니다.
  3. 검증 통과 상품만 자동 공개 발행 대기열에 등록합니다.
  4. 쿠팡 발행 도우미가 카테고리 42·전체공개·URL 기록을 검증한 뒤 자동 발행합니다.

쿠폰·와우 조건부 최저가는 조건 문구와 함께 표시합니다. 여행·품절·이미지 미검증·일반가 미검증 상품은 자동 발행하지 않습니다.
