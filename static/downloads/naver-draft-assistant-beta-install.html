네이버 초안 입력 도우미 베타

버전 0.4.2입니다. 설치한 사용자만 blogauto.hongzi.us에서 만든 초안을 네이버 글쓰기 화면에 자동으로 입력할 수 있습니다.

0.4.2 ZIP 다운로드

  1. ZIP 파일을 압축 해제합니다.
  2. Chrome 주소창에 chrome://extensions를 입력합니다.
  3. 오른쪽 위의 개발자 모드를 켭니다.
  4. 압축해제된 확장 프로그램을 로드합니다를 누르고, 압축을 푼 naver-draft-assistant 폴더를 선택합니다.
  5. 기존 설치본이 있다면 새로고침 아이콘을 눌러 0.4.2인지 확인합니다.

이 확장 프로그램은 제목·본문·이미지 입력만 돕습니다. 게시, 저장, 예약, 공개 상태 변경은 자동으로 실행하지 않으며 사용자가 직접 처리합니다.
